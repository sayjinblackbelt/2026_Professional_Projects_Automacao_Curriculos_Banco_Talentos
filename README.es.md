# 2026 Professional Projects — Automatización de Currículos y Banco de Talentos

Automatización de la generación de currículos y organización de un banco de talentos mediante Google Forms, Google Sheets, Google Docs y Google Apps Script, aplicada a procesos de inclusión productiva y derivación profesional.

## Propósito

Este repositorio documenta un proyecto práctico de automatización destinado a reducir tareas administrativas repetitivas y mejorar la organización de información profesional.

## Tecnología

- Google Forms
- Google Sheets
- Google Docs
- Google Apps Script

## Privacidad

El repositorio contiene solamente documentación. Los datos personales de candidatos y la información sensible no deben subirse a Git.
