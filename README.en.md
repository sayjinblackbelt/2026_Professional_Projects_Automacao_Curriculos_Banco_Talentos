# 2026 Professional Projects — Resume Automation & Talent Database

Automation for resume generation and talent-pool organization using Google Forms, Google Sheets, Google Docs and Google Apps Script, applied to productive inclusion and professional referral processes.

## Purpose

This repository documents a practical automation project designed to reduce repetitive administrative work and improve the organization of professional candidate information.

## Technology

- Google Forms
- Google Sheets
- Google Docs
- Google Apps Script

## Privacy

The repository contains documentation only. Personal candidate data and sensitive information must not be committed to Git.
